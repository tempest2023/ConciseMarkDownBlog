Work & Research

I build agents for complex workflows and co-author research on structured generation, precise editing, and tool use. Here are the problems, approaches, and public sources behind that work.

Agent engineering

Nova Agent

Production agents · Insurance

Problem. Insurance operators work across large document sets and internal services to prepare contracts and communications.

My work. I work on agent system design and production engineering around tools, skills, memory, document processing, permissions, and human review. Work on quoting and placement services informs how I integrate the agent with the surrounding workflow.

Approach. The workflow connects policy and submission documents to generated artifacts that operators can inspect. A single task can involve more than 50 PDFs.

TikTok coding agent

Developer tooling · Code migration

Problem. Migrating Objective-C code to Swift requires generated code that is useful within an existing engineering workflow.

My work. I built the internal agent from scratch, including code-generation loops and custom evaluation harnesses, and iterated on prompts and generated code.

Approach. Evaluation was part of the development loop: generated code was checked and refined for practical migration work. My mobile product engineering experience helped ground the tooling in developer needs.

Selected research

FineEdit

Findings of EMNLP 2025

Problem. Instruction-driven edits must preserve surrounding content and respect the structure of code, LaTeX, and database languages.

Research. Co-authored FineEdit, connecting a specialized editing model with the InstrEditBench benchmark for targeted modifications.

Approach. The research evaluates precise edits across structured domains and extends evaluation to multi-turn editing scenarios.

Read the paper

TreeDiff

SURGeLLM at ACL 2026

Problem. Random token masking in diffusion language models does not capture the syntactic boundaries and hierarchical dependencies of code.

Research. Co-authored TreeDiff, a syntax-aware diffusion framework that uses abstract syntax tree structure in the corruption process.

Approach. The method masks tokens belonging to selected AST nodes, aligning reconstruction with program structure. Published in the SURGeLLM workshop proceedings at ACL 2026.

Read the paper

Infant Agent

Agent research · arXiv preprint, 2024

Problem. Multi-step engineering and reasoning tasks need coordination beyond a single model response.

Research. Co-authored research on a tool-integrated, logic-driven agent architecture with task-aware functions and hierarchical management.

Approach. The work studies memory retrieval, tool integration, and API costs, with evaluations on software engineering and mathematical reasoning tasks.
