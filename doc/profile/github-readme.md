# Tao Ren (Tempest)

**AI Engineer & Researcher** · Agents, structured generation, and evaluation

I build agents for document-heavy workflows and software engineering, and study how language models edit and generate structured content.

At Newfront, I work on **Nova Agent** for insurance operations. Previously at TikTok, I built an internal **Objective-C-to-Swift coding agent** with iterative generation and custom evaluation harnesses. My full-stack and mobile engineering background helps me connect model capabilities with tools, production services, and human review.
