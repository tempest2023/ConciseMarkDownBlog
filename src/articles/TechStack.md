# Technical Background

I work across agent systems, model evaluation, and product engineering. The projects below show how I use those capabilities in practice.

## Agent systems

Tool use, memory, task decomposition, document processing, structured outputs, and human-in-the-loop review. My focus is the path from a user request to artifacts that can be inspected and used within an existing workflow.

**In practice:** [Nova Agent](/?page=Work#nova-agent), [TikTok coding agent](/?page=Work#tiktok-coding-agent), and [Infant Agent](/?page=Work#infant-agent).

## Evaluation and model research

Code-generation evaluation harnesses, prompt iteration, instruction-driven editing, and structure-aware generation. My research also covers real-time inference under changing environmental conditions.

**In practice:** [FineEdit](/?page=Work#fineedit), [TreeDiff](/?page=Work#treediff), and [RED](https://ieeexplore.ieee.org/abstract/document/10405986).

## AI product interfaces

Full-stack applications, mobile interfaces, streaming interactions, and operator review flows. I use prototypes to explore what users need to see and control when working with AI.

**In practice:** [AgentShelf](https://github.com/tempest2023/AgentShelf), [Obi](https://github.com/tempest2023/Obi), and [Live Subtitles](https://github.com/tempest2023/live-subtitles).
